Assignment (express-db branch)
This week's task: build Express MVC app with MySQL database.

Did the endpoints
- GET /api/media - list media
- GET /api/media/:id - get media by id
- POST /api/media - upload media file
- PUT /api/media/:id - update media
- DELETE /api/media/:id - delete media
- GET /api/users - list users
- GET /api/users/:id - get user by id
- POST /api/users - create user
- PUT /api/users/:id - update user
- DELETE /api/users/:id - delete user
- GET /api/likes/media/:id - get likes for media
- GET /api/likes/user/:id - get user likes
- POST /api/likes - add like
- DELETE /api/likes/:id - remove like

How to run
```bash
npm install
npm run init-db
npm start
```
